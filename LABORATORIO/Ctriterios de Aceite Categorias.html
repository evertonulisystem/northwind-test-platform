Azure DevOps - Laboratório Selenium

Funcionalidade: Cadastro de Categorias

Objetivo da Funcionalidade

```

Permitir que usuários autenticados realizem o cadastro de novas categorias para utilização no cadastro de produtos.

```

Critérios de Aceite

```
ID Critério Resultado Esperado
CA01 Informar nome válido Campo aceito sem exibir erro
CA02 Informar descrição válida Campo aceito sem exibir erro
CA03 Clicar em Salvar com dados válidos Categoria cadastrada com sucesso
CA04 Usuário sem token Mensagem "Você precisa estar logado"
CA05 Cadastro realizado Modal fechado e formulário limpo
```

Regras de Validação Front-End

```
Campo Regra Mensagem
Nome Obrigatório Nome da categoria é obrigatório
Nome Mínimo 2 caracteres Deve ter entre 2 e 50 caracteres
Nome Máximo 50 caracteres Deve ter entre 2 e 50 caracteres
Descrição Obrigatória Descrição é obrigatória
Descrição Mínimo 10 caracteres Deve ter entre 10 e 200 caracteres
Descrição Máximo 200 caracteres Deve ter entre 10 e 200 caracteres
```

Mensagens Esperadas

```
Cenário Mensagem
Nome vazio Nome da categoria é obrigatório
Nome inválido Deve ter entre 2 e 50 caracteres
Descrição vazia Descrição é obrigatória
Descrição inválida Deve ter entre 10 e 200 caracteres
Cadastro com sucesso Categoria cadastrada com sucesso!
Sem autenticação Você precisa estar logado
Falha de rede Erro de rede
```

Casos de Teste Selenium

```
ID Caso de Teste Resultado Esperado
CT001 Tentar salvar sem preencher nome Exibir mensagem de obrigatoriedade
CT002 Tentar salvar sem preencher descrição Exibir mensagem de obrigatoriedade
CT003 Nome com 1 caractere Exibir validação de tamanho
CT004 Nome com 51 caracteres Exibir validação de tamanho
CT005 Descrição com menos de 10 caracteres Exibir validação
CT006 Descrição com mais de 200 caracteres Exibir validação
CT007 Cadastro válido Toast de sucesso
CT008 Cancelar cadastro Modal encerrado
```

Elementos para Automação

data-testid="add-category-btn" data-testid="category-name-input" data-testid="category-description-input" data-testid="save-category-btn" data-testid="cancel-category-btn" data-testid="error-category-name" data-testid="error-category-description"
