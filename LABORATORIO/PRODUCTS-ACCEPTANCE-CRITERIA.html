📋 Critérios de Aceite - Products

Teste de API com Playwright

🎯 Objetivo do Teste

Validar todos os endpoints da API de Products garantindo que as regras de negócio, validações e respostas HTTP estejam conforme especificado.

📦 GET /api/v1/products - Listar Produtos

GET /api/v1/products?page=1&limit=10&search=mouse&category_id=1&supplier_id=1&sort=price&order=desc

Query Parameters

  • page (opcional) Número da página para paginação (padrão: 1, mínimo: 1)
  • limit (opcional) Quantidade de itens por página (padrão: 10, máximo: 100)
  • search (opcional) Busca textual no nome do produto (case insensitive)
  • category_id (opcional) Filtrar por ID da categoria (deve existir)
  • supplier_id (opcional) Filtrar por ID do fornecedor (deve existir)
  • sort (opcional) Campo de ordenação: name, price, stock_quantity, created_at
  • order (opcional) Direção da ordenação: asc, desc (padrão: asc)

Status Codes Esperados

200 400 401 500

Critérios de Aceite

  • ✅ Listagem com paginação funcional Retorna produtos paginados com metadados (page, limit, total, totalPages)
  • ✅ Filtros funcionando corretamente Aplica filtros de categoria, fornecedor e busca textual
  • ✅ Ordenação por múltiplos campos Permite ordenar por nome, preço, estoque e data
  • ✅ Token obrigatório Requer JWT válido no header Authorization
  • ✅ Validação de parâmetros Valida page/limit como números positivos

➕ POST /api/v1/products - Criar Produto

POST /api/v1/products

Body (JSON)

  • name (obrigatório) Nome do produto (3-100 caracteres, único)
  • price (obrigatório) Preço (número > 0, 2 casas decimais)
  • stock_quantity (obrigatório) Quantidade em estoque (inteiro ≥ 0)
  • sku (obrigatório) SKU único (6-20 caracteres, maiúsculas, alfanumérico)
  • category_id (obrigatório) ID da categoria existente (inteiro > 0)
  • supplier_id (obrigatório) ID do fornecedor existente (inteiro > 0)

Status Codes Esperados

201 400 401 409 500

Critérios de Aceite

  • ✅ Criação com sucesso Produto criado com slug gerado automaticamente
  • ✅ Validação de campos obrigatórios Retorna erro se campos obrigatórios ausentes
  • ✅ Validação de unicidade Impede SKU ou nome duplicados
  • ✅ Validação de tipos Verifica tipos dos dados (number, string, integer)
  • ✅ Slug automático Gera slug a partir do nome automaticamente

📦 GET /api/v1/products/{id} - Buscar Produto

GET /api/v1/products/{id}

Path Parameters

  • id (obrigatório) ID do produto (inteiro positivo, deve existir)

Status Codes Esperados

200 400 401 404 500

Critérios de Aceite

  • ✅ Busca por ID funcional Retorna produto específico com todos os dados
  • ✅ Validação de ID Valida ID como número positivo
  • ✅ Produto não encontrado Retorna 404 se produto não existe
  • ✅ Dados relacionais Inclui nome da categoria e fornecedor

✏️ PUT /api/v1/products/{id} - Atualizar Produto

PUT /api/v1/products/{id}

Body (JSON) - Todos os campos obrigatórios

  • name (obrigatório) Nome completo do produto (3-100 caracteres)
  • price (obrigatório) Preço (número > 0, 2 casas decimais)
  • stock_quantity (obrigatório) Quantidade em estoque (inteiro ≥ 0)
  • sku (obrigatório) SKU único (6-20 caracteres, maiúsculas)
  • category_id (obrigatório) ID da categoria existente
  • supplier_id (obrigatório) ID do fornecedor existente

Status Codes Esperados

200 400 401 404 409 500

Critérios de Aceite

  • ✅ Atualização completa Atualiza todos os campos do produto
  • ✅ Slug regerado se nome mudar Gera novo slug se nome for alterado
  • ✅ Validação de unicidade Verifica SKU e nome duplicados
  • ✅ Produto não encontrado Retorna 404 se produto não existe

🔧 PATCH /api/v1/products/{id} - Atualização Parcial

PATCH /api/v1/products/{id}

Body (JSON) - Pelo menos um campo obrigatório

  • name (opcional) Nome do produto (3-100 caracteres, gera novo slug)
  • price (opcional) Preço (número > 0, 2 casas decimais)
  • stock_quantity (opcional) Quantidade em estoque (inteiro ≥ 0)
  • sku (opcional) SKU único (6-20 caracteres, maiúsculas)
  • category_id (opcional) ID da categoria existente
  • supplier_id (opcional) ID do fornecedor existente

Status Codes Esperados

200 400 401 404 409 500

Critérios de Aceite

  • ✅ Atualização parcial funcional Atualiza apenas os campos enviados
  • ✅ Pelo menos um campo obrigatório Retorna erro se nenhum campo for enviado
  • ✅ Slug regerado apenas se necessário Gera slug apenas se nome for alterado
  • ✅ Validação de campos individuais Valida apenas os campos enviados
